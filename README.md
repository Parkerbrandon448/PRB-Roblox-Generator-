# PRB Roblox Creator Studio

A mobile-first web experience for an AI-powered Roblox game creation platform.

## Features

- Conversational AI creator prompts
- Project generation preview
- Asset studio for UI, models, music, beats, emotes, and UGC
- Marketplace-style asset discovery
- Export actions for `.rbxl`, `.rbxlx`, `.obj`, `.fbx`, and `.gltf`
- Responsive interface for desktop and mobile

## Run

Open `index.html` directly in a browser or serve the repository with any static web server:

```bash
python3 -m http.server 4173
```
